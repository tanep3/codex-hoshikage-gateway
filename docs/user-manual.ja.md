# ユーザーマニュアル

[English](user-manual.md) · [まだ導入していない方へ](installation.ja.md)

Codex Hoshikage Gatewayは、Discordのいつもの投稿からCodexへ作業を頼めるBotです。導入済みなら、特別な「会話開始」操作はいりません。

## 話しかける

許可されたDiscordサーバーで、テキストチャンネルまたはフォーラム投稿を開いて話しかけてください。設定が「メンション時だけ」なら、Botを `@` で呼び出してから送信します。チャンネルごと、フォーラム投稿ごとに会話が続き、作業ファイルも別のフォルダーへ保存されます。フォルダーを自分で登録する必要はありません。

通常の投稿は新しい依頼です。先の作業が終わっていなければ待機します。**今動いている作業への補足**をすぐ伝えたいときは `/steer` を使います。Botが「入力中…」と表示することがあります。これは作業中の目印で、完了の保証ではありません。

このBotを操作できるのは、設置時に指定された本人だけです。ただし、チャンネルを見られる人には会話の投稿も見えます。個人的な内容は非公開のチャンネルで話してください。

## よく使うコマンド

Discordの入力欄で `/` を入力し、Botのコマンドを選びます。例えば `/model id:...` の `id` はDiscordに表示される入力欄です。

| コマンド | できること |
| --- | --- |
| `/status` | この会話の実行中・待機列・選択モデル・推論レベル・会話状態を見る |
| `/models` | 使えるモデルIDを一覧で見る。続きは `page` 欄で指定 |
| `/model` | 選択中のモデルを見て、メニューから変更 |
| `/model id:モデルID` | モデルIDを直接指定。次の依頼から使用 |
| `/effort` | 選択中の推論レベルを見て、このモデルで使える候補から変更 |
| `/effort level:推論レベル` | 推論レベルを文字列で直接指定。次の依頼から使用 |
| `/workspace` | この会話の作業ファイルの保存先を見る |
| `/get` | この会話で登録された成果物の一覧を見る |
| `/get path:output/report.pdf` | 作業フォルダー内のファイルをDiscordへ送る。**相対パス**を入力 |
| `/steer text:追加指示` | 実行中の作業に補足や方向修正を送る |
| `/cancel` | 直近の待機依頼を1件取り消す。待機がなければ実行中の作業へ中断を要求 |
| `/stop` | 実行中の作業へ中断を要求し、後続の待機列も一時停止 |
| `/resume` | `/stop` で止めた待機列を再開。止めた作業自体はやり直さない |
| `/recover` | 前の作業が結果不明で会話が止まったとき、説明を確認して新しい文脈で再開 |

モデルと推論レベルは会話ごとに保存されます。ある会話で変えても、別の会話には影響しません。初めて使う会話では、管理者が `config.direct.toml` に設定した既定値から始まります。

`/cancel` は「今受け付けた指示を取り消したい」とき、`/stop` は「作業と後続の待機列を止めたい」ときに使います。中断要求の受付と、実際の終了確認は別です。必要なら `/status` で確認してください。作業中に行ったファイル変更などが自動で元に戻るわけではありません。

## スキル

管理者がGatewayの共通スキルとして追加したものは、どのDiscordチャンネルやフォーラム投稿からでも使えます。チャンネルごとに同じスキルを作り直す必要はありません。ある会話だけの作業手順として置いたスキルは、その会話だけで使えます。

共通スキルの実際の保存先や追加方法は、管理者向けの[導入・設定手順](installation.ja.md#全チャンネルで使うスキル)を確認してください。

## ファイルと画像

投稿には画像、テキスト、動画、音声、PDFなどのファイルを添付できます。動画を加工してほしい場合は、動画を添付して「先頭と末尾を切って」「ffmpegで音声を抜き出して」のように、そのまま依頼してください。画像は画像入力として、小さなテキストは本文として、それ以外のファイルはこの会話専用の作業フォルダーへ保存してCodexへ渡します。

サイズや件数の上限を超えたものは受け付けません。その場合は、ファイルを小さくする、分割する、もう一度添付するなど、次にできることをBotが案内します。「AIへは送信していません」と表示された依頼は実行されていないため、案内に従って新しい投稿で送り直してください。

Codexが作った画像は通常、同じ会話に自動で届きます。文章より後に届く場合もあります。

ほかの成果物は `/get` を開いて一覧を確認してください。ファイル名や保存場所が分かっているなら `/get` の `path` 欄に `output/report.pdf` のような相対パスを入れます。`/workspace` に表示される絶対パスを貼る必要はありません。`/get` は**取得した時点のファイルを保存した版**を送ります。元ファイルが後から変わっても、すでに保存した版は変わりません。送信結果が分からない場合、重複を避けるため自動で送り直しません。まず会話内に添付が届いていないか確かめてください。

## 許可を求められたら

Codexがコマンド実行やMCPツール操作などの確認を求めると、会話にカードが出ます。「自分だけに表示して確認」を押して、**操作内容・入力値を最後まで読みます**。長い内容はページを進めて確認します。内容を理解できた場合だけ許可してください。「今回だけ許可」はその操作1件だけです。対象のMCP操作では「この依頼中、このツールを許可」が表示される場合があり、同じ依頼中の同じツールの後続呼出しにも適用されます。引数や対象が変わる場合もあるため、範囲を理解して選んでください。

内容が分からない、表示されない、許可したくない場合は「拒否」または「取り消し」を選べます。作業全体を止めたい場合は `/stop` を使います。ボタンを押した後、ツールの結果は続くCodexの回答で確認します。許可ボタンを押したこと自体はツールの成功を意味しません。

## 会話が止まったとき

Botが「前の作業の結果を確認できない」と案内したら、同じ依頼を連投せず、まず `/status` を確認します。案内に `/recover` がある場合は、同じ会話で `/recover` を開いてください。画面には、何が残り、何が取り消されるかを表示します。納得したら **「新しい文脈で会話を再開」**を押し、次の新しい投稿から続けます。**前の作業は再実行されず、Discord履歴と作業ファイルは残ります。未送信の待機依頼は取り消され、Codexの会話文脈は新しくなります。** 必要な指示だけ改めて投稿してください。

`/recover` で解除できない場合は、まだ作業中の可能性があります。`/status` と必要なら `/stop` を使い、解決しなければGatewayの運用者へ相談してください。`/resume` だけでは結果不明の依頼は解除されません。サービスの再起動も、止まったAI作業を自動でやり直す操作ではありません。

設置や設定を変更する人向けの手順は[導入・設定手順](installation.ja.md)、サービスの確認方法は[運用・復旧ガイド](operations.ja.md)にあります。
