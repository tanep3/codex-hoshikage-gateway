# ユーザーマニュアル

[English](user-manual.md) · [導入手順](installation.ja.md)

この資料はAPI v2向けです。現在は受入試験中で、[残作業と検証状況](implementation-status.ja.md)があります。本番利用の開始を案内する版ではありません。

## 話しかける

許可されたサーバーの通常チャンネルやフォーラム投稿で話しかけてください。cwdや `/project` の登録は不要です。通常チャンネルはチャンネルごと、スレッドやフォーラムは投稿ごとに会話を持ちます。

Botが全投稿に答えるか、メンション時だけ答えるかは運用設定で選べます。設定済みのモデルを使い、選択が必要なときはモデルメニューを表示します。

## モデルと作業の操作

| 操作 | 使い方 |
| --- | --- |
| `/new title:会話名` | 任意：別のスレッド／フォーラム投稿をBotに作らせる |
| `/workspace` | 会話を始める前に共有ワークを選ぶ（通常は不要） |
| `/retry` | 未配信・結果不明の回答／成果物を選び、確認後に同じ保存版を再送 |
| `/get scope:shared` | 明示的に共有ワーク全体の成果物を選ぶ |
| `/models` | 利用できるモデルの一覧 |
| `/model` | 選択中モデルの確認。未選択ならメニュー |
| `/model id:モデルID` | 次の依頼からモデル変更。同じProvider内で会話を継続 |
| `/status` | 会話、選択／実行モデル、停止状態、Proxy接続を確認 |
| `/steer text:追加指示` | 現在のTurnに指示を追加。通常投稿は次の依頼として待機 |
| `/stop` | 待機列を一時停止し、受付済みの依頼を停止。開始前でも操作可能 |
| `/resume` | 待機列を再開。停止した依頼をやり直す操作ではない |

停止の受付と、実際に停止したことは別です。確認できない場合は不明と案内します。承認が必要なときは、表示された対象と内容を確認してボタンで回答してください。

## ファイルを渡す・受け取る

画像やUTF-8テキストは投稿に添付できます。容量上限を超えた入力は実行しません。

`/get`を開くと登録済み成果物を選べます。モデルの専用登録ツールで保存されたファイルが対象です。未登録のファイルは `/get path:output/report.pdf` のように相対パスで指定できます。絶対パスは不要です。

選んだartifact IDの内容は固定です。同じ版の再送と、更新後の原本から新しい版を作る操作を区別します。一覧は25件ずつ「次のページ」で進めます。選択画面は10分間有効です。期限が切れたら `/get` で開き直してください。配信のやり直しは `/retry` で選び、重複の可能性を確認してから実行します。AIの作業はやり直しません。

## 接続が切れたら

Gatewayの接続切断だけではProxyの実行は止まりません。停止したいときは `/stop` を使います。確定回答と成果物はProxyの保存期限内で再取得し、Gatewayのキャッシュが消えても同じIDを使います。保存失敗・期限切れ・権限撤回では回収できない場合があります。AIを自動再実行して回答を作り直すことはありません。

実行状態が不明なら通常操作で解除せず、運用者がProxyを確認します。復元世代が変わった場合も管理照合が必要です。旧会話や管理解除後のワークを使う手順は[運用ガイド](operations.ja.md)を参照してください。

## ファイルを共有して作業したいとき

通常は会話ごとに専用の作業先が用意されます。別の会話とファイルを共有したい場合だけ、最初に話しかける前に `/workspace` で候補を選んでください。configやホストのパスを登録する必要はありません。共有ワークでは、別の会話からの変更も見えます。

すでに作業先が決まっている会話は変更できません。別の作業先を使いたい場合は、Discordで別の投稿を作り、そこで選んでください。フォーラム内なら同じフォーラムに新しい投稿ができます。タグ必須のフォーラムはDiscordの「投稿を作成」を使ってください。

[運用ガイド](operations.ja.md)

いつもの場所で普通に話しかければ会話を受け付けます。`/new` は会話を始めるための必須操作ではありません。
